URI Encoding Demo

Original (with special characters):

https://example.com/search?query=HTML & CSS

Correct encoded version (spaces -> %20, ampersand in the query needs encoding as %26):

https://example.com/search?query=HTML%20%26%20CSS

Note: When a query value contains an ampersand (&), encode it as %26 so it is not treated as a separator between parameters.
