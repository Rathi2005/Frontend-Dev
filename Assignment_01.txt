1. Explain the difference between frontend, backend, and full-stack development with suitable real-world examples.
Answer:
The frontend is the part of a website that we can see and use directly. It includes the layout, buttons, colors, and text on the screen. For example, when we open Amazon, the product images, search bar, and “Add to Cart” button are all part of the frontend.
The backend works behind the scenes. It handles things like login, storing data, and sending information to the frontend. For example, when you log in to Instagram, the backend checks if your username and password are correct.
A full-stack developer works on both frontend and backend. For example, a developer who builds a restaurant booking site designs the web pages (frontend) and also creates the system that saves bookings in a database (backend).

3. Describe how a browser requests and displays a web page from a web server.
Answer:
When we type a website address in a browser, the browser sends a request to the web server. The server finds the page and sends it back to the browser. The browser then reads the HTML, CSS, and JavaScript and shows the complete page to the user. Images, styles, and scripts are also loaded during this process.

5. Explain what a web server is and give examples of commonly used servers.
Answer:
A web server is a computer program that stores website files and sends them to users when they open a website. It handles requests from browsers and gives the right response.
Examples: Apache, Nginx, Microsoft IIS, and Node.js (with Express).


6. Define the roles of a frontend developer, backend developer, and database administrator in a project.
Answer:
    • Frontend Developer: Designs how the website looks and makes it easy to use. Works with HTML, CSS, and JavaScript.
    • Backend Developer: Builds the system behind the website, handles user data, and connects the website to the database.
    • Database Administrator (DBA): Manages and secures the database, makes backups, and ensures everything runs smoothly.
